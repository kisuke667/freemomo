## 🎬 Ce que fait FREEMOMO

Pipeline **7 étapes** verrouillées, 100% autonome :

| Étape | Module | IA fait quoi ? | Livrable |
|-------|--------|----------------|----------|
| **1** | Clés API | Multi-fournisseurs (Agnès, Higgsfield, KIE…) | — |
| **2** | Style Motion | Choix parmi 6 familles (Minimal, 3D, Énergie, Rétro…) | `P.genre` |
| **3** | Brief | Brief → concept + 10 alternatives → fusion | `P.final` |
| **4** | Brand Kit | Logo/typo/couleurs/icônes + styleframes | Styleframes |
| **5** | Séquences | `n` séquences (3/5/8/12) + textes à animer | **Traitement exportable** |
| **6** | Keyframes | 3-5 keyframes/séquence (2-4s) + easing | **Découpage exportable** |
| **7** | Rendu | File vidéo (Agnès/Kling/Veo/Runware) + animatic | Vidéos + SRT |

> **Livrables dès l'étape 5** — pas besoin d'attendre le rendu.

## ⚡ Fonctionnalités

- **6 familles motion** : Minimal (kinetic, geometric), 3D & Depth (clay, glass), Énergie (glitch, liquid, particle), Rétro, Corporate (infographie, app, logo reveal), Cinématique (title, parallax)
- **Higgsfield-grade UI** : obsidienne `#060608`, lime `#E8FF42`, `Space Grotesk` + `JetBrains Mono`, header studio `FM`, pilules, verre dépoli
- **iPhone-first** : `viewport-fit=cover`, `16px` anti-zoom, header stack 980px, grilles 1col, `44px` touch
- **Livrables** : `⬢ LIVRABLES — prêts dès l'étape 5` → JSON/MD/CSV/HTML/SRT + header `⬇`
- **Providers vidéo** : 7 adaptateurs (Agnès, Pollinations, Runware, KIE, WaveSpeed, Magic Hour, Higgsfield)

## 🚀 Utilisation

1. `index.html` ou https://freemomo.vercel.app
2. Étape 1 : fournisseur + clé
3. Étape 2 : style motion + ratio
4. Étape 3 : brief (ex: "Reveal logo néon streetwear, glitch, Born to Move") → Analyser → Valider
5. Étapes 4-6 : génère, retouche, **exporte dès séquences**
6. Étape 7 : Lancer le rendu → vidéos + SRT
